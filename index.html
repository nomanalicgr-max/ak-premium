Unlock PDF

For a password-protected PDF, enter the password. This rebuilds a text PDF from the extracted text in your browser. Layout may change. It does not crack or guess a password.

Protect PDF

Standard PDF password encryption needs a native engine and is not faked here. This tool encrypts the whole file in your browser with AES-GCM and downloads a .akenc file. Only this Unlock tool, with the same password, can open that .akenc file again. It is not a standard password-protected PDF.

Frequently Asked Questions

        
What is AK Premium?
AK Premium is a free, browser-based toolkit with PDF tools and an Excel automation engine. It creates, merges, splits, rotates and converts PDFs, and generates Excel formulas, VBA macros, regex patterns and DAX measures.

        
Is AK Premium free?
Yes. The built-in tools are free to use in your browser, with no paid API required.

        
Do files leave my browser?
No. Built-in tools process files locally in your browser using client-side JavaScript. Files are not uploaded to a server by AK Premium.

        
How do I merge PDFs?
Select Merge PDF, choose two or more PDF files in the order you want, and download the combined PDF. All merging happens in your browser.

        
How do I remove pages or add a watermark?
For Remove Pages, select a PDF and enter the pages to delete, for example 2, 4-5. The tool checks them against the real page count and downloads a copy with those pages removed. For Add Watermark, enter text and choose opacity and size; it is stamped diagonally on every page. A watermark is a visible mark, not document security.

        
How do I convert between Excel and CSV?
Excel to CSV exports the first sheet of an .xlsx file as a .csv download. CSV to Excel accepts an uploaded .csv file or pasted CSV text and downloads it as an .xlsx file. Both run in your browser with SheetJS.

        
What image tools are available?
Image Compressor re-encodes images as JPEG at your chosen quality, Image Resizer changes width and height, Image Converter changes JPG, PNG or WebP format, and Image to Text reads printed text from an image with OCR.

        
What everyday, developer and calculator tools are available?
QR Code Generator makes a downloadable QR PNG, Password Generator makes a random password with crypto.getRandomValues, and Word Counter counts words, characters, sentences, paragraphs and reading time. JSON Formatter formats, minifies and validates JSON, and Base64 encodes or decodes text. Calculators compute exact age, percentages and BMI.

        
What are the limits of OCR, image compression and PDF editing?
OCR downloads language data on its first run and may take time; it works best on clear printed text and is not reliable for handwriting or low-quality photos. Image Compressor output is JPEG, so transparency is flattened. Edit PDF adds new text only; it does not edit or delete existing text in a PDF.

        
How do I generate an Excel formula?
Open Formula Generator, describe what you want in plain words — for example sum with a condition — and AK Premium returns a template formula you can adapt with your own cell ranges.

        
How does each tool work?
Select a tool card to open its workspace. PDF tools use pdf-lib, pdf.js and jsPDF in your browser: Create PDF writes text with jsPDF, Images to PDF places each image on its own page, Merge combines pages in your selected order, Split extracts a page range, Remove Pages deletes the pages you list after checking them against the real page count, Rotate rotates every page, Add Page Numbers stamps a number at the bottom of each page, Add Watermark stamps your text diagonally on every page, and Compress re-saves the PDF. Converters extract text where a text layer exists and rebuild a simple file in the target format; Excel to CSV exports the first sheet as CSV and CSV to Excel rebuilds an .xlsx from CSV text. The Excel engine is rule-based: it matches keywords in your description and returns a formula, VBA, regex or DAX template — it does not call a paid API and does not run against your workbook.

        
What are the limits?
Compressing a PDF in the browser does not fully recompress embedded images, so image-heavy PDFs may shrink only a little. Protect PDF is not a standard PDF password: it encrypts the whole file in your browser with AES-GCM and downloads a .akenc file, which only this site's Unlock tool with the same password can reopen. Unlock PDF for a standard password PDF rebuilds a text PDF from the extracted text, and layout may change. The e-Sign canvas produces a visual signature PNG only; it is not a legal digital signature or certificate-based signing. PDF to Word, PDF to PPT and PPT to PDF are text-based, so original layout, fonts, tables, images, charts and animations are not preserved. Scanned-image PDFs without a text layer cannot be read by text extraction. Generated formulas, VBA, regex and DAX are templates that have not been run against your workbook or model; replace placeholders with your own ranges, sheet names and columns, and test on a copy of your data first. The placeholder password in the advanced VBA template must be changed before real use.

        
Privacy
AK Premium does not collect, store or transmit your uploaded files. Built-in tools run in your browser. If you later connect Google Analytics, only the anonymous usage data described by Google Analytics will be collected, and only after a measurement ID is added. AK Premium does not sell personal data and does not require an account to use the built-in tools.

        
Terms
Tools are provided as-is, for lawful use only. Do not upload files you do not have the right to use, and do not use generated templates, VBA or DAX code in production without reviewing and testing it in your own workbook. Keep original copies of important files.

        
How do I open a category page?
Use the top navigation: All Tools, PDF Tools, Convert, Excel Tools, Image Tools, Everyday Tools, Developer Tools, Calculators, Business Tools, Design Tools, or FAQ. Each button shows only that category, like its own page, and updates the URL hash (for example #pdf, #calculators, #business) so the page is shareable. Searching shows matching tools from all categories, and clearing the search returns to the selected category.

        
How do I make an invoice?
Open Invoice Generator in Business Tools, enter the business name, client name, date, and one item per line as: Item name, quantity, price. AK Premium calculates the subtotal, tax and total, shows a summary, and downloads a clean PDF invoice. Invoice PDFs are simple formatted PDFs, not Word templates.

        
How do I build a resume?
Open Resume Builder in Business Tools, enter your name, job title, contact details, skills and experience, and download a clean PDF resume with a name and title header, contact line, Skills and Experience sections.

        
How do I calculate CGPA?
Open CGPA Calculator, enter one course per line as: Course, credit hours, grade point — for example Math, 3, 3.7. AK Premium computes the weighted CGPA as the sum of credit hours times grade points divided by total credit hours, shown to 2 decimals. It uses the grade points you enter.

        
How do I calculate a loan EMI?
Open Loan / EMI Calculator, enter the loan amount, annual interest rate and years. AK Premium computes the monthly EMI with the standard EMI formula, plus total payment and total interest. A 0% rate is handled as the amount divided by the number of months.

        
What developer and design tools are available?
Case Converter changes text to UPPERCASE, lowercase, Title Case or Sentence case. UUID Generator makes secure random UUIDs. CSV to JSON turns a header row and data rows into a JSON array of objects. Text Diff Checker compares two texts line by line. Color Palette builds a base, complementary, analogous and triadic palette from one color, with click-to-copy hex codes.

        
Google Analytics and AdSense
Google Analytics can be connected by setting GA_MEASUREMENT_ID in app.js and redeploying; gtag loads only when that value is non-empty. AdSense code can be pasted into the labelled ad placeholders on the page. Approval is decided by Google. For pixel-perfect conversion of complex layouts, app.js also holds empty optional integration points for ConvertAPI and CloudConvert (free tier, 1,000 monthly actions); no key is required for the built-in tools, and no conversion is faked when a key is absent.

              
What new PDF tools were added in this version?
Unlock PDF, Protect PDF, Crop PDF, Redact PDF, PDF to PDF/A, Repair PDF, Compare PDF, PDF to Markdown, Scan to PDF, OCR PDF, PDF Forms, Local Summarizer and Translate Helper. All existing AK Premium tools are still here.

        
Do files leave my browser?
No. Built-in tools process files locally in your browser. Library files load from public CDNs, but your PDF, image and spreadsheet files are not uploaded to an AK Premium server.

        
Why is Protect PDF not a standard PDF password?
Standard PDF password encryption needs a native engine like QPDF. The free browser libraries used here cannot encrypt a PDF to the standard format, so AK Premium does not fake it. Protect here encrypts the whole file in your browser with AES-GCM, and only the matching Unlock step can open that file again.

        
Why is there no AI Translate or AI Summarizer?
Those would need an external AI service, which would send your document off your browser. The local summarizer picks key sentences in your browser, and Translate Helper extracts text for translation elsewhere, so your file stays local.

        
How do I use the More menu?
Top navigation keeps All Tools, PDF Tools, Convert, Excel Tools and FAQ visible. Click More to open a vertical dropdown with Image Tools, Everyday Tools, Developer Tools, Calculators, Business Tools and Design Tools.

        
Which PDF tool should I use to organize, optimize or secure a PDF?
For organizing, use Merge PDF, Split PDF, Organize PDF, Remove Pages or Rotate PDF. For optimizing, use Compress PDF, PDF to PDF/A or Repair PDF. For security, use Unlock PDF or Protect PDF. For intelligence, use Compare PDF, OCR PDF, Local Summarizer or Translate Helper.

        
Can I preview a file before converting it?
Yes. When you choose a PDF, AK Premium shows its name, size and page count, and renders page 1 as a preview right under the file chooser, before you press Convert, so you can confirm it is the right document. Images show a thumbnail the same way. The preview is made in your browser and the file is not uploaded.

        
Is AK Premium really free and private?
Yes. The built-in tools are free in your browser with no sign-up, and your files are processed locally in your browser, not uploaded to an AK Premium server.
