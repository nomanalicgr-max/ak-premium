Protect PDF

Real standard PDF password encryption (AES-256, qpdf). The file stays a normal .pdf and opens in Acrobat and Chrome with the password you set. Keep the password safe, it cannot be recovered.

Files up to 50 MB. The password is used in your browser only and is never sent anywhere.

What Protect PDF does

Protecting a PDF is for files that should only be opened by someone who knows the password: a salary slip, a contract draft, a fee receipt or a report with personal details. The password travels with the file, so it works in Acrobat and Chrome without any account.

How to use Protect PDF

  1. Choose your PDF file using the file button above.
  2. Set any options the tool shows, such as a page range, a password or a quality level.
  3. Press the main button and download or copy your result. Your file stays in your browser.

Tips for a good result

Use a password you can remember or store safely, because there is no way to recover it. A password of 8 or more characters with letters and numbers is much harder to guess than a short word.

Limits to know about

The tool uses standard AES-256 PDF encryption (qpdf, revision 6). It does not stop someone from photographing the screen or re-sharing the file once they have opened it, and a forgotten password cannot be recovered by this site.

Example

Protecting a salary slip with a password means only the person who knows that password can open it in a PDF reader.
