What Regex Creator does

A regex creator is for finding or checking a pattern in text: an email address, a Pakistan mobile number, a CNIC, a date, or a web link. It is used in spreadsheets, text editors and data cleaning, where a pattern is faster than reading every line.

How to use Regex Creator

  1. Pick the task from the list, then fill in the labelled fields with your own ranges and values.
  2. Press Generate.
  3. Copy the result and paste it into Excel, then test it on a copy of your data.

Tips for a good result

Paste some of your own text in the test box and press Generate. The tool shows you exactly which parts matched, so you can see if the pattern is right before you use it anywhere else.

Limits to know about

The tool gives you a fixed pattern for a named task. It does not build a pattern for a new, unusual format, and a pattern that matches your test text may still miss a different format of the same thing.

Example

Choosing Pakistan mobile number gives 03\d{2}[- ]?\d{7}, which finds 0317-7483793 and 03177483793.

What is a regex?

A regular expression is a short pattern that describes a shape of text, such as an email address. A program can then find every piece of text with that shape.

Yes, with VBA, or in Google Sheets with REGEXEXTRACT. Paste the pattern exactly as shown, including the backslashes.
