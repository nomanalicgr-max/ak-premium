v31 — 24 November 2026 (advanced upgrade plan, batch 11: Image converters + design/everyday)

PNG to JPG — quality, background colour, EXIF orientation

  • Pick the JPEG quality, choose the colour used to fill a transparent background, and let photos rotate the right way up from their EXIF data before converting. The result is a standard JPEG that opens anywhere.

JPG to PNG — smaller PNG-8 files, exact colours for simple images

  • Simple images with few colours are now saved as PNG-8, which is much smaller than a full-colour PNG, and the colours are kept exactly. Photos still use a full-colour PNG. Every PNG-8 file is checked before it is saved, and if the check fails the tool falls back to a full-colour PNG and says so.

WebP to JPG — quality, background colour, EXIF orientation

  • Convert WebP pictures to JPEG with a quality slider and a background colour for transparent areas, and let photos rotate the right way up from their EXIF data. The result is a standard JPEG that opens anywhere.

WebP to PNG — smaller PNG-8 files, EXIF orientation

  • Simple WebP images with few colours are now saved as PNG-8, which is much smaller than a full-colour PNG, and the colours are kept exactly. Photos still use a full-colour PNG, with the same check-and-fallback as JPG to PNG, and photos are rotated the right way up from their EXIF data.

JPG to WebP — quality, Best-quality mode, target size, EXIF orientation

  • Save JPG photos as WebP with a quality slider, a Best-quality mode, or a target file size that the tool aims for by trying lower qualities. Photos are rotated the right way up from their EXIF data. Browsers cannot write a truly lossless WebP file, so Best-quality is a high-quality lossy save and the page says so plainly.

Image Compressor — EXIF toggle, honest note about location data

  • A new switch chooses whether the photo's EXIF information is kept or stripped when it is compressed. Re-saving a photo never keeps its location data, and the page says so.

Passport Photo Maker — NADRA and driving-licence sizes, guide overlay, print sheets

  • Ready sizes for NADRA and Punjab driving-licence photos (35 by 45 mm), with a head oval and shoulder line over the photo to help line the face up. Colour Palette — WCAG contrast, harmonies, shades, eyedropper, exports

  • Check any two colours against the WCAG AA and AAA contrast rules, build palettes from six harmony types, and see shades and tints from 50 to 900 for every colour. Colours can be typed as hex, RGB, HSL or a colour name, or picked from a photo with the eyedropper. Palettes export as CSS variables, Tailwind config or a PNG image.

QR Code Generator — structured types, error correction, logo, scan test

  • Build QR codes for a web link, Wi-Fi network, contact card, email, SMS, phone number, location or payment, with a size choice, error-correction level from L to H, custom colours and a logo in the centre. Codes save as PNG or SVG, and a built-in scan test reads the code back to confirm it works. The QR library was changed to one that supports SVG and error-correction control.

Password Generator — passphrases, strength and crack time

  • A new passphrase mode makes passwords from words, using a 1,296-word sample of the EFF large wordlist (the full 7,776-word list was not shipped). Strength and an estimated crack time are shown for every password, using zxcvbn. There are also modes that leave out look-alike characters, make pronounceable passwords, and make PIN codes.

Image Converter — TIFF, BMP, GIF and ICO input, batch conversion

  • Now accepts JPG, PNG, WebP, AVIF, BMP, GIF, ICO and TIFF files, and converts several images at once into JPG, PNG, WebP or AVIF, with a ZIP download for the batch. TIFF files are decoded in the browser (UTIF.js), photos are rotated the right way up from their EXIF data, and the EXIF data can be kept or stripped. GIF output is a still image, not an animation, ICO files are square so wide images are fitted inside, JPEG-compressed TIFF files cannot be decoded here, and AVIF output needs a browser that can save AVIF.

Image to Text — OCR pre-processing and word confidence

  • Before reading, the image is tidied for you: sideways photos are fixed from their EXIF orientation, pages are straightened, contrast is raised, the image is turned grey and enlarged for small text. The result is now word by word with a confidence score, and words the reader is unsure about are highlighted. The language is detected automatically when it can be. It reads printed text only, not handwriting.

Image Cropper — aspect lock, rotate while cropping, straighten

  • Drag a box over the photo to choose what stays, with the box locked to a shape like square, 16 to 9 or 3 to 2. You can rotate the photo while cropping, straighten a tilted photo and flip it, then save as JPG, PNG or WebP at your chosen quality. The cropper needs the Cropper.js library from the internet, so it will not start when you are offline.

SVG to PNG — scales, icon presets, backgrounds, more outputs

  • Scale an SVG to 1x, 2x or 3x its own size, type an exact width and height, or pick a ready icon size from 16 up to 512 pixels. The background can stay transparent or be filled with a colour, and the result can be saved as PNG, JPG, WebP or AVIF. An SVG that loads pictures or fonts from the internet cannot be converted here, because the browser blocks those outside files.

Rotate and Flip Image — arbitrary angle, straighten, batch

  • Rotate in 90 degree steps or by any angle with the straighten slider, flip a photo left to right or top to bottom, and let photos rotate themselves the right way up from their EXIF data. Several photos can be rotated at once and downloaded as a ZIP. Straightening turns the picture by a few degrees and fills the corners with the image edge, so a small part of the corners is lost.

Image Resizer — social and print presets, face-aware crop

  • Ready presets for Instagram posts and stories, Facebook posts, YouTube thumbnails, LinkedIn posts, WhatsApp and passport photos, plus A4 at print DPI. Pick the output format and quality. Face-aware crop uses the FaceDetector built into Chrome, so other browsers crop from the centre instead, and AVIF output needs a browser that can save AVIF.

PNG to PDF — transparency control, grids, JPEG toggle

  • Transparency can now be kept (where the PDF allows it) or flattened onto white, black or a colour of your choice, handy when the PDF will be printed.   • Resolution is now a choice from 72 to 300 DPI, with a quality slider, a grayscale toggle and a resize-to-width preset for smaller images. Only the pages you need can be exported, and a single page downloads on its own without a ZIP. Each page becomes a separate picture, so a long PDF means many images and a large ZIP.

PDF to PNG — DPI, transparency, rename pattern

  • Resolution is now a choice from 72 to 300 DPI, with transparent-background PNG where the page itself has no background colour (a page with a white background stays white). Page-range export, single-page download without a ZIP, and a file-name pattern that names every image for you: report-p{nn}.png becomes report-p01.png, report-p02.png and so on.

HTML to PDF — real rendered pages via html2canvas

  • Pasted or uploaded HTML is now rendered as it looks in a browser (html2canvas), not converted to plain text: headings, lists, tables, colours and layout are kept, links stay clickable, and a font, size and page-size choice is offered. Scripts, event handlers and javascript: links are stripped before rendering, and head style blocks are kept. If the page cannot be rendered, the tool falls back to an honest plain-text PDF and says so. Pasting a web address is not supported, as there is no server to fetch it.

Extract Images from PDF — original format and bytes

  • Images are now saved in the exact format and bytes stored in the PDF (JPEG, JPEG2000 and JBIG2), byte-identical to the original, with no duplicate listing and a download link per image plus one ZIP for all of them. Vector drawings (lines and shapes drawn by the PDF itself) are not pictures and are not extracted; use PDF to Images for a picture of the whole page.

Add Header and Footer to PDF — variables, scope, logo

  • Header and footer text now support {page}, {total} and {date} variables, a font, size, colour and alignment choice, and a page scope: all pages, odd or even pages only, all except the first, or the first page only. A different first page is supported, and a logo image (PNG or JPG) can be placed in the header or footer. The stamp is drawn as text on each page, so it stays selectable.

Flatten PDF — qpdf annotation flattening, field report

  • Flattening now uses qpdf, so form fields and annotations (comments, highlights, stamps) are rendered into the page itself, with links kept working. Three modes: fields only, annotations only, or both, plus a field report listing what was flattened and a downloadable text copy of the report. Flattening cannot be undone, so keep the original file. Annotations with no appearance to draw are left in place by qpdf, and the report says how many are left.

PDF Metadata Editor — XMP packet, remove-all preset

  • Title, author, subject and keywords can now be edited together with creator, producer, creation date and modification date, written into an XMP packet inside the file, and a "remove all personal metadata" preset clears title, author, subject, keywords, creator and producer in one click. One honest limit: the PDF library always writes its own name as the Producer in the file properties and stamps the save time as the Modification Date, so those two typed values can only be kept in the XMP packet, not in the file properties.

Resize PDF Page Size — in-place vector resize

  • Pages are now resized in place, so text stays selectable and drawings stay vector, with nothing re-rendered or blurred. Form fields and links are scaled with their pages, including link rectangles and highlight areas. A4, Letter and Legal presets, a custom size in millimetres, and a per-page choice (all pages, or a list like 2-3, 5) so only the pages that need it are resized and the cover page can keep its size.

PDF to Markdown — headings, tables, images

  • Headings now come from font size and layout, with lists, bold and italic from the font data. Tables become Markdown tables using the same grid inference as PDF to Excel, and images in the file are extracted and linked as `![](image-N.png)`. The download is a single `.md` file, or a ZIP of the Markdown plus its images when images exist.

Scan to PDF — multi-photo batch, auto-crop, deskew, OCR layer

  • Several photos can now be turned into one PDF in a single run, one photo per page. Page edges are auto-cropped and tilted photos straightened with the same pure-code deskew as Rotate PDF (no opencv.js, so nothing large is downloaded). An optional OCR text layer makes the scan searchable, with a language picker; a Cancel button stops a long run, and per-photo progress and errors name the file.

OCR PDF — more languages, searchable PDF

  • The language picker now offers English, Urdu, Arabic, Hindi, English+Urdu, English+Arabic and Auto (which detects the script on the first page). The output is now a searchable PDF: the original page picture with an invisible word text layer over it, so the text can be selected and searched. Handwriting recognition is not offered: it needs a cloud OCR model and the page says so.

Organize PDF — thumbnails, duplicate, split, blank, extract

Remove Pages — visual picker, blank pages, text search
