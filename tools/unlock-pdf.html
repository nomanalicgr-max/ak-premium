Unlock PDF

Removes the password from a standard password-protected PDF you own, keeping the original pages and layout. You must know the password. This tool does not guess or crack passwords.

What Unlock PDF does

Unlocking is for a PDF you own and know the password for, but no longer want to type it every time you open it. It is also the way to get a clean copy of a protected file for printing or for a tool that does not accept protected PDFs.

How to use Unlock PDF

  1. Choose your PDF file using the file button above.
  2. Set any options the tool shows, such as a page range, a password or a quality level.
  3. Press the main button and download or copy your result. Your file stays in your browser.

Tips for a good result

Make sure you type the exact password, including capital letters. A wrong password gives a clear wrong-password message, not a broken file.

Limits to know about

The tool does real standard PDF decryption and keeps the original pages and layout. It does not guess or crack passwords, and it cannot unlock a file whose password you do not know.

Example

Unlocking a protected fee receipt gives you an ordinary PDF that opens without a password.

Your privacy

Your files are processed in your browser by Unlock PDF. They are not uploaded to an AK Premium server, and you do not need an account to use the tool. The libraries the tool needs load from public CDNs, and those CDNs may log standard technical information, such as your IP address, when they serve a library file. If you later accept cookies, Google AdSense and Google Analytics may set their own cookies, as described in the Privacy Policy.

Frequently asked questions

Is Unlock PDF free?

Yes. Unlock PDF on AK Premium is free to use in your browser, with no sign-up and no account.

No. AK Premium tools run in your browser, so the files you choose are not uploaded to an AK Premium server. The libraries the tool needs load from public CDNs, but your files stay on your device.

How do I use Unlock PDF?

Open the tool on this page, follow the steps under How to use, and download or copy your result. The steps are written for this tool, not for a general PDF editor.

The tool does real standard PDF decryption and keeps the original pages and layout. It does not guess or crack passwords, and it cannot unlock a file whose password you do not know.

It removes the password properly and downloads a normal PDF with the original pages and layout. It is not the old text-only rebuild.

What if the PDF is not protected?

The tool checks first and tells you the PDF is not password-protected, so you do not waste time on a file that does not need unlocking.
